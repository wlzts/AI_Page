曹继贤 · 可玩简历 V6 可视化编辑模式
====================================

一、怎么编辑
1. 双击 index.html 打开网站。
2. 点击页面右上角「✎ 编辑资料」。
3. 左侧选择：个人资料 / 工作经历 / 教育经历 / 项目经历 / 技能 / 证书成就。
4. 直接在表单里修改。
5. 点击右下角「保存并应用」。
6. 页面自动刷新，普通简历与 RPG 游戏会同时使用最新资料。

二、保存在哪里
默认保存在当前浏览器的本地存储（localStorage）中。
只要使用同一个浏览器、同一个 index.html 路径再次打开，修改后的资料会自动加载。

注意：如果移动整个项目文件夹、换浏览器、清理浏览器数据，本地保存可能无法继续读取。
所以建议重要修改后点击「导出 JSON」做一份备份。

三、换电脑 / 换浏览器
旧电脑：编辑资料 → 导出 JSON
新电脑：编辑资料 → 导入备份 → 保存并应用

四、恢复原始资料
编辑资料 → 恢复默认 → 保存并应用
会恢复 resume-data.js 中自带的曹继贤资料。

五、永久写回项目文件（可选）
编辑资料 → 导出 resume-data.js
浏览器会下载一个新的 resume-data.js。
如果你希望把当前资料直接固化进项目，可以用它替换项目根目录原来的 resume-data.js。
这不是正常使用的必需步骤；平时直接点「保存并应用」即可。

六、快捷键
Ctrl + S（Windows）/ Command + S（Mac）：编辑模式中快速保存。
Esc：退出编辑模式（有未保存内容时会先提示）。
