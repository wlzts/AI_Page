曹继贤 · 履历冒险 FINAL
========================

这是一个完全离线、免安装的可玩像素 RPG 个人简历。

打开方式
--------
1. 解压整个文件夹。
2. 双击 index.html。
3. 普通网页简历会直接打开。
4. 点击“开始冒险”进入像素 RPG 履历小镇。

不需要安装 Node.js、npm、VS Code、Phaser，也不需要本地服务器或网络。

最重要：以后只改一个文件
----------------------
只需要编辑：

    resume-data.js

网页模式和游戏模式都会读取这一份数据。
不要分别修改页面文字和游戏文字。

你可以在 resume-data.js 中维护：
- 姓名、英文名、职位、所在地、邮箱
- 个人简介、职业方向、价值观、兴趣
- 工作经历
- 教育经历
- 项目经历
- 技能和 1~5 级能力等级
- 证书与项目里程碑
- GitHub / LinkedIn / 个人网站
- 简历 PDF 路径

目前已经填入曹继贤已确认的资料。
学校名称、工作时间、真实简历 PDF、GitHub/LinkedIn 等未提供的信息没有擅自编造，配置文件中保持“暂未填写”或空字符串。

技能等级说明
------------
当前技能等级是根据已提供的真实技术栈、职责和项目内容进行的保守推断。
等级只使用 1~5，不使用“Java 95%”这类虚假百分比。
你可以在 resume-data.js 中自行调整 level。

简历 PDF
--------
当前没有真实简历 PDF，所以网页和游戏会自动隐藏下载入口。
以后有 PDF 后：
1. 用真实 PDF 覆盖根目录 resume.pdf
2. 打开 resume-data.js
3. 把：

    resume: ""

   改成：

    resume: "resume.pdf"

保存后下载入口会自动出现。

游戏操作
--------
W / A / S / D 或方向键：移动
Shift：奔跑
空格 / Enter：互动 / 继续对话
M：打开地图
Esc：关闭对话 / 地图 / 信息窗口
R：脱困 / 重置到当前区域安全位置

游戏区域
--------
关于我的小屋：个人简介、价值观、兴趣、职业方向
职业高塔：工作经历、职责、技术栈、核心能力
大学与学院：教育、课程、实训、证书
项目实验室：两个核心后端项目与技术难点
技能训练馆：Java 后端、数据缓存、工程化、系统性能、基础能力
成就博物馆：证书与已确认的项目里程碑
联系车站：邮箱与未来补充的社交/简历链接

离线特性
--------
- 不使用 fetch() 读取本地 JSON
- 不依赖 ES Module
- 不依赖 CDN
- 不需要 localhost
- 所有主要资源都在本地目录

美术与授权
----------
第三方 CC0 素材与原创资产说明见 LICENSES.txt。

游戏展台容量
------------
当前室内美术布局支持：
- 工作经历：最多 4 段（Career Tower 4 个展台）
- 核心项目：最多 6 个（Project Lab 6 个终端）
- 技能分组：最多 5 组（Skill Gym 5 个训练区）
- 成就/证书：最多 4 个（Museum 4 个主展柜）

普通网页模式不会受这些展台数量限制；如果未来需要更多游戏展台，可以再扩建房间。

============================================================
V6 可视化编辑模式
============================================================
现在不需要手动编辑 resume-data.js。

打开 index.html 后，点击右上角「✎ 编辑资料」即可进入编辑模式。
支持直接编辑：
- 个人资料 / About
- 工作经历
- 教育经历
- 项目经历
- 技能与等级
- 证书 / 成就
- Email / GitHub / LinkedIn / 简历链接

支持新增和删除工作经历、教育经历、项目、技能、证书/成就。
点击「保存并应用」后会保存到当前浏览器并自动刷新，普通简历与游戏同时更新。

为了在换电脑、换浏览器或移动文件夹时避免本地资料丢失，建议定期点击「导出 JSON」。
需要恢复时进入编辑模式点击「导入备份」。
详细说明见：编辑模式说明.txt
